音だけで、場所を旅する。

きこえる地図プロジェクトは、日本各地の「環境音」を地図に残し、写真ではなく音でその場所の空気を届けるオープンソースプロジェクトです。

きこえる地図をひらく プロジェクトについて

きこえる地図の 3 つの特長

  • 1

    音で旅する地図

    地図のピンをタップすると、その場所の音が流れます。駅のざわめき、川のせせらぎ、夏祭りのお囃子。目を閉じても、その場所に立っているような体験を。

  • 2

    誰でも音を残せる

    アカウントは不要です。スマートフォンのブラウザで録音して、場所を選んで、そのまま投稿できます。あなたの街の音が、誰かの旅になります。

  • 3

    オープンソース

    ソースコードはすべて GitHub で公開しています。使う人・音を残す人・つくる人が一緒に育てていく地図です。

できること

すべての機能を見る

  • 聴く・聴き比べる

    波形付きのプレイヤーで再生。同じ場所の朝と夜、晴れと雨を重ねて聴き比べることもできます。

  • 散歩モード

    各地の音をなめらかにつないで再生し、地図がその場所へゆっくり移動します。

  • 音の風景

    地図の中心に立って、周りの音を立体的に。歩き回ると聞こえ方が変わります。

  • みみあて

    音だけを頼りに場所を当てるゲーム。毎日のお題とランキングも。

  • 散歩コース

    テーマに沿って選ばれた音を、ルートをたどりながら順番に聴けます。

  • 音を投稿する

    録音、トリミング、場所の選択まで、ブラウザだけで完結します。

はじめかた

  1. 地図をひらくきこえる地図にアクセスします。インストールもアカウント登録も要りません。
  2. ピンをタップして聴く気になる場所のピンを選ぶと、下のパネルで音が流れます。ヘッドホンがおすすめです。
  3. 散歩モードで流しっぱなしに「散歩」ボタンを押すと、各地の音が次々に流れます。作業のおともにもどうぞ。
  4. あなたの街の音を残す「投稿」ボタンから録音して、地図に音を置いてみましょう。
